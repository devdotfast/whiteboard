# Security Policy

Report a suspected Whiteboard or diffr vulnerability through this repository's
private GitHub security advisory form. Do not open a public issue.

You can also report vulnerabilities privately to security@dev.fast. Please
include the affected version, reproduction steps, and potential impact.

Do not report Whiteboard issues to Microsoft. The security document under
`apps/review-desktop/code-oss/` applies to Microsoft's VS Code project.

If an issue originates in Code - OSS, report it to Microsoft and to us when it
also affects Whiteboard.
