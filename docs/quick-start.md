# Quick start

1. [Install Whiteboard](installation.md) and open the app.
2. [Connect your agent](connect-your-agent.md). For example, with Claude Code
   on macOS or Linux:

   ```sh
   claude plugin marketplace add devdotfast/whiteboard
   claude plugin install whiteboard@devfast --scope user
   ```

3. In your repository, ask your agent:

   ```text
   Review changes from my current branch against main and open the result in Whiteboard.
   ```

See [Create a review](create-a-review.md) for what happens next.
