# Troubleshooting

## Logs

Press F1 in Whiteboard and run **Developer: Open Logs Folder**. Each launch
writes a folder named for its start time. `main.log` in that folder has the app
and review server logs.

The logs live here:

- macOS: `~/Library/Application Support/Whiteboard/logs/`
- Linux: `~/.config/Whiteboard/logs/` (or `$XDG_CONFIG_HOME/Whiteboard/logs/`)
- Windows: `%APPDATA%\Whiteboard\logs\`

Preview builds use `Whiteboard Preview` in place of `Whiteboard`.

## Report a problem

In a review, select the bug icon in the top bar to report a bug. It can include
the review, its diff, and a screenshot. You can also search
[GitHub issues](https://github.com/devdotfast/whiteboard/issues) before opening
one. Include your app and agent versions, operating system, reproduction steps,
and exact error text.

For questions, ask on [Discord](https://discord.gg/wYvd2cpMQg).
