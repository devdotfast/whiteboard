# Contributing

- Read `AI_POLICY.md` before opening a pull request.
- Run `cargo fmt --all`, `cargo test --locked` and `typos` locally; CI
  runs the same.
- Keep pull requests to one change. Describe what changed and why in the
  description; the merge squashes it into the history.
- Bug reports use the issue template. Include the diffr version and the
  inputs that reproduce the problem.
