---
name: deslop-ui
description: Clean up canvas UI code generated by AI in packages/review/app. Use after writing or changing canvas components or styles, before review.
---

Review every canvas file the branch changed (`git diff origin/main --stat -- packages/review/app`). Assume each new style or component is a copy of something the kit already has, and prove otherwise before you keep it.

- **Hand-rolled controls.** Search `src/ui/` before keeping any of these, and swap in the kit piece:
  - a `<button>` with its own padding, border, background and font: use `Button`, `IconButton` or `buttonStyles.reset`
  - a local `<input>`, `<textarea>` or `<select>` look: use `TextField`, `TextArea`, `Select`, `Checkbox` or `Switch`
  - a click-outside effect: use `Popover` or `useDismissOnOutside`
  - a fixed overlay: use `Dialog`
  - a rotating chevron: use `DisclosureChevron` with `chevronMarker`
  - a border-ring spinner: use `Spinner`
  - a copied-state timer: use `useCopy`
  - a sidebar or menu row with its own hover wash: use `listRowStyles`
  - a rounded chip with an inset ring: use `pillStyles`
  - a notification dot: use `StatusDot`
  - `title=` on an icon control: use `useTooltip`
- **Local icons.** An inline `<svg>` or a glyph used as an icon (`×`, `›`, `▾`, `✓`, `…`) belongs in `ui/icons.tsx`, drawn on its 24 grid and sized with `iconStyles`. Agent marks go through `AgentLogo`.
- **Repeated fragments.** These become kit fragments:
  - `overflow: hidden` + `textOverflow: ellipsis` + `whiteSpace: nowrap`: `textStyles.truncate`
  - two-line clamps: `textStyles.clamp2`
  - error colors: `textStyles.error`
  - focus outlines: `focusStyles.ring` / `ringInset`
  - 1px vertical rules: `dividerStyles.vertical`
  - bordered figures: `surfaceStyles.card`

  A pattern that appears a third time goes in the kit.
- **Off-scale values.** `pnpm lint` catches literals. Don't silence it with a new step or an inline `calc()`. Snap to the nearest step, and name a geometry-coupled offset once. Reduced-motion and 720px queries become `stylex.env.reducedMotion` / `stylex.env.narrow`; a one-off layout breakpoint may stay local. Replace local `spin` keyframes and easings with `motion.*` and `spinStyles`.
- **Every animation stills under reduced motion.** Check each `animationName` and `transition` has a `stylex.env.reducedMotion` branch.
- **Focus.** Look for anything that sets `disabled` on the button that was just pressed (Send, Retry, an opener while it loads). Replace it with a guard in the handler. Popovers and dialogs must close on Escape and give focus back to their trigger.
- **Portals.** UI portaled outside `.review-app` needs `themeStyles.vars`, or kit controls lose their chrome tokens and collapse.
- **Feedback placement.** Errors inside a modal render inline with `role="alert"`. Transient success after a surface closes uses `notify`. Don't do both.
- **Slop in styles.** Delete:
  - comment-per-property styles
  - `!important`
  - descendant selectors (use markers or variants)
  - `zIndex` literals that stack across surfaces (use `layer`; order inside one component may stay local)
  - shadows outside `elevation`
  - `transparent` literals (use `tokens.transparent`)
  - duplicate `stylex.create` blocks that differ by one property (use a variant)
- **Tests.** Don't add tests that assert class names, CSS text or style objects. Test behaviour (roles, focus, dismissal) and check the visuals in the Desktop.

Then:

1. Run `pnpm format`, `pnpm lint` and `pnpm -w exec tsc --noEmit -p packages/review/app` from the repo root.
2. Run the canvas tests for the files you touched.
3. Check the changed surfaces in an isolated Desktop (`DEV_FAST_REVIEW_DESKTOP_BACKGROUND=1`): dark, light, a narrow width, keyboard focus and reduced motion.
4. Report what you replaced, and anything you kept local and why.
